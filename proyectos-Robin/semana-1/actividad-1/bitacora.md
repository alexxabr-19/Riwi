Comandos

1. pwd -> Permite saber en qué carpeta estoy ubicada en la terminal.
2. cd .. -> Permite regresar a la carpeta anterior.
3. ls -> Lista los archivos y carpetas que hay en mi ubicación actual.
4. ls -l -> Es similar a ls, pero este comando muestra información más detallada, como permisos y tamaño.
5. mkdir -> Permite crear una carpeta.
6. touch -> permite crear archivos.
7. echo -> Permite escribir un texto en un archivo desde la terminal.
8. rm -> Permite eliminar un archivo.
9. rm -r -> Permite eliminar una carpeta.
10. rmdir -> Permite eliminar una carpeta que esté vacía.
11. cat -> muestra el contenido de uno o varios archivos.
12. mv -> permite mover un archivo a otra carpeta o cambiarle el nombre.
13. cp -> Permite copiar un archivo.
14. cp -r -> Permite copiar una carpeta.
15. find -> Permite buscar archivos o carpetas.

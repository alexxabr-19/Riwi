# Algoritmos en PSeInt

## Semana 1

### Descripción

En esta actividad se realizaron 4 ejercicios de algoritmos en PSeInt, utilizando variables, operadores y estructuras de decisión.


## Pruebas de los algoritmos

Se realizaron dos pruebas para cada uno de los cuatro algoritmos, utilizando diferentes valores de entrada para comprobar sus resultados.

### 1. Credenciales

Este algoritmo verifica si el usuario y la contraseña son correctos.

| Prueba | Usuario | Contraseña | Resultado |

| 1 | hola | chao | Acceso concedido |
| 2 | hola | 1234 | Acceso denegado |

### 2. Edades

Este algoritmo determina si una persona es mayor o menor de edad.

| Prueba | Nombre | Edad | Resultado |

| 1 | Juan | 20 | Mayor de edad |
| 2 | Ana | 16 | Menor de edad |

### 3. Número mayor

Este algoritmo compara dos números para determinar cuál es mayor o si son iguales.

| Prueba | Número 1 | Número 2 | Resultado |

| 1 | 10 | 5 | El número 10 es mayor |
| 2 | 4 | 8 | El número 8 es mayor |

### 4. Triángulos

Este algoritmo compara tres lados para clasificar el triángulo.

| Prueba | Lado 1 | Lado 2 | Lado 3 | Resultado |

| 1 | 5 | 5 | 5 | Equilátero |
| 2 | 5 | 5 | 3 | Isósceles |


### Aprendizaje

Con estos ejercicios aprendí a utilizar variables, comparaciones y condiciones "Si" y "SiNo" para tomar decisiones dentro de un algoritmo.

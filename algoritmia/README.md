# Algoritmos en PSeInt

## Descripción

Este repositorio contiene los ejercicios que he realizado durante las diferentes semanas de aprendizaje de algoritmia en PSeInt.

En estas actividades he practicado el uso de variables, condiciones, ciclos y SubProcesos, con el objetivo de comprender mejor la lógica de programación.

Los ejercicios están organizados por semanas y algunos incluyen tablas de verdad, pruebas de escritorio y tablas de traza.
